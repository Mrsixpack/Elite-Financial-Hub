## 🚀 Deployment

### **Development**
```bash

npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start with PM2 (sandbox)
```

```bash
# Deploy to Cloudflare Pages
npm run deploy

# With custom project name
npm run deploy:prod
```
