## 🚀 Deployment

### **Development**
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start with PM2 (sandbox)
pm2 start ecosystem.config.cjs
```

### **Production (Cloudflare Pages)**
```bash
# Deploy to Cloudflare Pages
npm run deploy

# With custom project name
npm run deploy:prod
```
